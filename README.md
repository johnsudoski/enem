# enem

Repositório de produtos e funis pra estudantes de ENEM/vestibular. Primeiro produto: **Desafio Reta Final — Protocolo 21 Dias**.

## Ao vivo

🔗 **https://johnsudoski.github.io/enem/**

`index.html` é o quiz "Diagnóstico de Aprovação" — 7 perguntas → resultado personalizado (1 de 4 perfis) → VSL de fechamento → checkout.

## Antes de rodar tráfego pra sério

Dois placeholders no topo do `<script>` de `index.html` ainda precisam ser preenchidos:

- `LEAD_WEBHOOK_URL` — URL de um formulário (ex.: Formspree) pra receber os leads capturados no quiz
- `TICTO_CHECKOUT_URL` — link do checkout real (Ticto/Hotmart/Kiwify) do produto

## Este repositório vs. o resto do produto

Aqui está só a parte pública (o quiz/funil). O produto pago em si (ebook, order bumps, upsell) fica fora deste repo, de propósito — é conteúdo entregue só depois da compra.

## Próximos produtos

Este repo é a base pra novos produtos da linha ENEM/vestibular — cada novo produto ganha sua própria página/pasta aqui quando existir.
